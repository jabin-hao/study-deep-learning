# 深度学习学习笔记

* 资料来源李沐老师《动手学深度学习课程》

* 本仓库用于整理与记录深度学习相关的学习资料与实践代码，包含多个框架版本（如 PyTorch、TensorFlow、MXNet、Paddle）。

## 目录结构

- `pytorch/`：PyTorch 版本内容
- `tensorflow/`：TensorFlow 版本内容
- `mxnet/`：MXNet 版本内容
- `paddle/`：Paddle 版本内容

## 使用说明

1. 进入对应框架目录。
2. 按章节打开并运行 `*.ipynb`。
3. 需要额外依赖时，请参考对应目录下的 `setup.py` 或相关说明。

## 说明

- 本仓库主要用于学习与实验记录。
- 大型数据集、模型权重和训练输出已通过 `.gitignore` 忽略。

## 许可

仅用于学习交流。
